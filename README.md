# Public Skills

可复用的 AI Agent 技能和指南，适用于 OpenClaw、Claude Code、Codex 等。

## Skills

| 技能 | 描述 | 核心原则 |
|------|------|----------|
| [goal-driven-thinking](./goal-driven-thinking/) | 以终为始，为行动而思考 | 🎯 Thinking 服务于目标 |
| [tree-structure](./tree-structure/) | 树状结构处理复杂任务 | 🌳 大任务拆小模块 |
| [cross-validation](./cross-validation/) | AI 互相检查 | 🔄 不让同一个 AI 既做题又判卷 |
| [memory-management](./memory-management/) | Agent 记忆组织 | 🧠 文件是唯一的长期记忆 |
| [multi-agent-workflow](./multi-agent-workflow/) | 多 Agent 协作 | 👥 分工协作，各司其职 |
| [incremental-verification](./incremental-verification/) | 增量验证 | ✅ 每做一步就验证一步 |

## 核心原则总结

```
🎯 以终为始     — Thinking 服务于目标，不是为了 thinking 而 thinking
🌳 树状结构     — 大任务拆小模块
🔄 交叉验证     — 不要让同一个 AI 既做题又判卷
🧠 记忆管理     — 文件是唯一的长期记忆
👥 多 Agent     — 分工协作，各司其职
✅ 增量验证     — 每做一步就验证一步
```

## 最重要的一句话

> **"Good thinking" = the most useful trace for sustaining action under real-world constraints, rather than the longest or most visible one.**
>
> 好的思考 = 在现实约束下支撑行动的最有用轨迹，而不是最长或最显眼的那个。
