# Public Skills

可复用的 AI Agent 技能和指南，适用于 OpenClaw、Claude Code、Codex 等 AI 工具。

## Skills

| 技能 | 描述 |
|------|------|
| [tree-structure](./tree-structure/) | 用树状结构处理复杂任务，减少 AI "遗忘"和错误传播 |

## 使用方式

这些 skill 可以：
1. 直接放入你的 agent workspace
2. 作为 CLAUDE.md / AGENTS.md 的参考
3. 复制相关原则到你的项目规则中

## 贡献

欢迎 PR！好的 skill 应该：
- 解决一个具体问题
- 有清晰的原则和示例
- 可独立复用
